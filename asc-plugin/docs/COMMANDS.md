## readiness

### `asc readiness`

Audit whether the app is ready for TestFlight and App Store submission. Exits 1 if any blocking check fails.

```
asc readiness [--app …] [--platform ios|macos|tvos|visionos] [--only appstore|testflight|local] [--json]
```

| Option | Description |
|---|---|
| `--only` | Limit to local | appstore | testflight |
| `--platform` | Platform to audit (default ios) |

Examples:

```sh
asc readiness
asc readiness --platform macos
asc readiness --only testflight --json
```

## api

### `asc api`

Call any App Store Connect API endpoint directly (escape hatch for anything not wrapped).

```
asc api <GET|POST|PATCH|DELETE> <path> [--query k=v ...] [--data <json|@file>] [--all]
```

| Option | Description |
|---|---|
| `--query` | Query param k=v (repeatable) |
| `--data` | JSON body, or @path/to/file.json |
| `--all` | Follow pagination (GET only) |

Examples:

```sh
asc api GET /v1/apps --query limit=5
asc api GET /v1/apps/123/betaGroups --all
asc api PATCH /v1/builds/abc --data '{"data":{"type":"builds","id":"abc","attributes":{"expired":true}}}'
```

## init

### `asc init`

Generate project configs: .asc.json, ExportOptions plists, metadata folder, .gitignore entries. Auto-detects the Xcode project.

```
asc init [--project X.xcodeproj | --workspace X.xcworkspace] [--scheme S] [--bundle-id com.x.y] [--team TEAMID] [--platform ios|macos] [--force]
```

| Option | Description |
|---|---|
| `--project / --workspace` | Xcode container (auto-detected) |
| `--scheme` | Scheme to build |
| `--bundle-id` | App bundle id |
| `--team` | Apple developer team id |
| `--platform` | ios|macos|tvos|visionos |
| `--force` | Overwrite existing files |

## builds

### `asc builds list`

List uploaded builds (newest first).

```
asc builds list
```

| Option | Description |
|---|---|
| `--app` | App |
| `--limit` | Max rows (default 25) |
| `--platform` | Filter by platform |

### `asc builds info`

Show one build (id, number, or "latest") with its TestFlight beta state.

```
asc builds info [<id|number|latest>]
```

### `asc builds next-number`

Print the next free build number (max existing + 1).

```

```

### `asc builds wait`

Block until a build finishes processing (VALID). Exit 1 on INVALID/timeout.

```
asc builds wait --number 42 [--timeout 45] [--interval 30]
```

| Option | Description |
|---|---|
| `--number` | Build number (CFBundleVersion) |
| `--timeout` | Minutes (default 45) |
| `--interval` | Seconds between polls (default 30) |

### `asc builds expire`

Expire a build so it can no longer be tested/submitted.

```
asc builds expire <id|number> --yes
```

### `asc builds encryption`

Answer export compliance for a build (usesNonExemptEncryption).

```
asc builds encryption <id|number|latest> --uses-encryption false
```

## ship

### `asc ship`

End-to-end: archive → export → upload → wait for processing → (TestFlight groups, what's new, beta review) → optional App Store version attach.

```
asc ship [--build-number auto|N] [--marketing-version X] [--group "Beta Testers,Internal"] [--notify] [--submit-beta] [--attach] [--skip-archive --ipa file] [--no-wait]
```

| Option | Description |
|---|---|
| `--build-number` | "auto" = latest + 1 (default auto) |
| `--group` | TestFlight group names/ids to add the build to (default: .asc.json testflight.groups) |
| `--notify` | Notify testers |
| `--submit-beta` | Submit for external TestFlight beta review |
| `--attach` | Attach the build to the editable App Store version |
| `--skip-archive` | Reuse an existing artifact |
| `--ipa` | Artifact path with --skip-archive |
| `--no-wait` | Do not wait for processing (disables later steps) |

## versions

### `asc versions list`

List App Store versions for the app.

```
asc versions list
```

| Option | Description |
|---|---|
| `--app` | App |
| `--platform` | ios|macos|tvos|visionos (default from config, else ios) |

### `asc versions create`

Create a new App Store version in PREPARE_FOR_SUBMISSION.

```
asc versions create --version 1.1 [--release-type MANUAL|AFTER_APPROVAL|SCHEDULED] [--earliest-release 2026-01-01T10:00:00Z] [--copyright "© 2026 Acme"]
```

| Option | Description |
|---|---|
| `--version` | Marketing version string |
| `--release-type` | MANUAL | AFTER_APPROVAL | SCHEDULED |
| `--earliest-release` | ISO date for SCHEDULED |
| `--copyright` | Copyright line |

### `asc versions update`

Update version attributes.

```
asc versions update [--version latest|<id>|1.1] [--release-type …] [--copyright …] [--new-version 1.2]
```

### `asc versions set-build`

Attach a processed build to a version.

```
asc versions set-build --build <buildId | latest | number> [--version latest]
```

| Option | Description |
|---|---|
| `--build` | Build id, build number, or "latest" |

### `asc versions delete`

Delete a version that has not been submitted.

```
asc versions delete --version <id|1.1> --yes
```

### `asc versions release`

Release an approved version that is PENDING_DEVELOPER_RELEASE (manual release).

```

```

### `asc versions phased-release`

Enable 7-day phased release for a version.

```
asc versions phased-release [--version latest]
```

## certs

### `asc certs list`

List signing certificates.

```
asc certs list
```

| Option | Description |
|---|---|
| `--type` | Filter: IOS_DEVELOPMENT, IOS_DISTRIBUTION, MAC_APP_DISTRIBUTION, MAC_INSTALLER_DISTRIBUTION, DEVELOPMENT, DISTRIBUTION, DEVELOPER_ID_APPLICATION … |

### `asc certs csr`

Generate a private key + certificate signing request with openssl (key stays on this machine).

```
asc certs csr --email you@x.com [--name "Your Name"] [--out ~/.keys/asc-signing]
```

| Option | Description |
|---|---|
| `--email` | Contact email |
| `--name` | Common name (default: Apple Distribution) |
| `--out` | Output prefix (default ./signing → signing.key, signing.csr) |

### `asc certs create`

Create a certificate from a CSR and save the .cer.

```
asc certs create --type IOS_DISTRIBUTION --csr signing.csr [--out dist.cer]
```

| Option | Description |
|---|---|
| `--type` | Certificate type |
| `--csr` | CSR file |
| `--out` | Where to save the .cer |

### `asc certs download`

Download an existing certificate as .cer.

```
asc certs download <id> [--out file.cer]
```

### `asc certs revoke`

Revoke (delete) a certificate.

```
asc certs revoke <id> --yes
```
